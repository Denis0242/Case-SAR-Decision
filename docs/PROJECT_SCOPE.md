# Project Scope

## Purpose
Simulate the analyst workflow after an AML alert has been escalated into a case.

## Workflow
Escalated case → customer/KYC review → transaction lookback → red-flag analysis → investigation summary → case disposition → SAR recommendation / filing decision → management reporting.

## In scope
- Case prioritization
- Transaction lookback
- KYC context
- Red-flag identification
- Investigation notes
- SAR decision support
- Case aging
- SAR conversion analytics
- Tableau executive reporting
- Streamlit investigation workbench

## Out of scope
- Filing real SARs
- Production case-management systems
- Machine-learning model development
- Automated regulatory reporting

All data is synthetic.
