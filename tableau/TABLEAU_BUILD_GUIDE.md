# Tableau Build Guide

## Project 5 — Approved Dashboard Design

### Visual standard
- Clean white background.
- Thin light-gray borders.
- ONE visualization color only: blue.
- Blue may use lighter/darker shades where separation is required.
- MM/YY date format, for example 07/26.
- Six KPI cards across the top.
- Exactly six analytical visualizations in a 3 x 2 grid.
- No stacked bar charts.

### KPI cards
1. Total Cases
2. High / Critical Cases
3. SAR Decisions
4. SAR Filed
5. Additional Review
6. Reviewed Amount

### Final six visualizations
1. Cases and SAR Decisions Trend
   - Combined trend lines for Total Cases, SAR Decisions, and SAR Filed.
2. Case Disposition
   - Donut chart using blue shades.
3. Top 5 Investigation Red Flags
   - Vertical bar chart.
4. Case Activity Heatmap (Day vs Hour)
   - Blue sequential heatmap.
   - Numbers centered inside cells.
5. Reviewed Amount vs Case Risk
   - Scatter plot.
6. SAR Conversion Rate by Case Type
   - Vertical bar chart.
